# 小程序上架配置清单

> 适用版本：M6-E（小程序功能开发冻结，仅做上架配置预留）
> 原则：**环境值不进代码**。AppID、服务器域名由构建脚本注入；AppSecret、支付密钥、证书路径只存后台，绝不下发小程序端。

---

## 1. 配置在哪里填

后台路径：**系统设置 → 小程序配置**（菜单名 `MksMiniprogramConfig`，配置分组 `miniprogram`）。

配置项一览（数据库表 `mks_config`，`vip_id=0`）：

| 配置键 | 名称 | 填写位置 / 说明 |
| --- | --- | --- |
| `mp_appid` | 小程序 AppID | 微信公众平台 → 开发管理 → 开发设置 |
| `mp_appsecret` | 小程序 AppSecret | 同上；仅服务端用于 `jscode2session`，不返回小程序端 |
| `mp_request_domain` | 服务器请求域名 | 小程序 request/uploadFile/downloadFile 合法域名，必须 HTTPS，例如 `https://mksup.top` |
| `mp_business_domain` | 业务域名白名单 | 微信公众平台 → 开发管理 → 业务域名；承载客服/协议 H5 页时必填，多个逗号或换行分隔 |
| `mp_pay_mchid` | 微信支付商户号 | 微信支付商户平台 → 账户中心 → 商户信息 |
| `mp_pay_apiv3_key` | 微信支付 APIv3 密钥 | 商户平台 → 账户中心 → API 安全；仅服务端 |
| `mp_pay_cert_path` | 微信支付证书路径 | 服务器绝对路径，如 `/opt/mkshop/cert/apiclient_cert.pem`（需挂载进 PHP 容器） |
| `mp_pay_cert_serial` | 微信支付证书序列号 | 商户平台证书详情页；与证书路径配套 |
| `mp_login_mode` | 登录方式 | `account` 账号密码（默认）/ `wechat` 微信授权 / `both` 两者都支持 |
| `mp_wechat_login_enable` | 启用微信授权登录 | 默认关闭；关闭时 `/mp/login/wechat` 返回「未启用」 |
| `mp_wechat_pay_enable` | 启用微信支付 | 默认关闭；关闭时继续使用余额支付，`/mp/pay/wechat` 返回「未启用」 |
| `mp_subscribe_templates` | 订阅消息模板 ID | 一行一个 `场景=模板ID`（如 `order_paid=xxxx`），也支持 JSON 对象 |
| `mp_kefu_url` | 客服链接 | 小程序客服页或企微客服链接；留空走站内客服 |
| `mp_privacy_url` | 隐私协议链接 | 必须 HTTPS，域名加入业务域名；提审要求填写隐私保护指引 |
| `mp_agreement_url` | 用户协议链接 | 建议与隐私协议同域 |
| `mp_release_enable` | 小程序上架开关 | 默认开启；关闭时登录页提示「暂未上架」，用于提审期冻结入口 |
| `mp_audit_status` | 审核状态备注 | 仅后台可见：记录版本号、提交时间、审核结果、驳回原因 |

> 上线前把 `mp_appid` / `mp_appsecret` / 域名 / 支付参数填好，再执行构建注入；**不要**把 AppSecret 写进小程序代码仓库。

### 后端公开接口

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/mp/config` | GET | 返回站点名、AppID、登录方式、微信登录/支付开关、订阅模板、客服/协议链接、上架开关；**不含任何密钥** |
| `/mp/login/wechat` | POST | 微信授权登录预留位；开关未开时返回「微信授权登录未启用」 |
| `/mp/pay/wechat` | POST | 微信支付下单预留位；开关未开时返回「微信支付未启用」 |
| `/mp/pay/notify` | POST | 微信支付回调预留位；开关未开时拒绝回调 |

访问方式与前台一致：`https://mksup.top/index.php?s=/mp/config`（`s` 参数需 URL 编码）。

## 2. 小程序端如何读取配置

1. **构建注入**（在 `miniprogram/` 目录执行）：

   Windows PowerShell：
   ```powershell
   $env:MP_APPID="wx1234567890"; $env:MP_BASE_URL="https://mksup.top"; node scripts/inject-config.js
   ```
   macOS / Linux：
   ```bash
   MP_APPID=wx1234567890 MP_BASE_URL=https://mksup.top node scripts/inject-config.js
   ```

   脚本会写入 `config.build.js` 并同步 `project.config.json` 的 `appid`。仓库中的默认值为空，未注入时小程序会提示「未配置服务器域名」。

2. **运行时配置**：`app.js` 启动调用 `/mp/config`，结果存入 `globalData.mpConfig`；登录页据此显示/隐藏「微信一键登录」、展示上架提示与协议链接。
3. **本地调试覆盖**：`wx.setStorageSync('mks_mp_base_url', 'http://154.222.25.115:8080')` 可临时覆盖请求域名（仅开发者工具使用）。
4. 现有 **账号密码登录 + 余额支付** 不受任何开关影响，默认即可用。

## 3. 送审前要准备的资料

### 3.1 主体与账号
- 小程序主体认证完成（企业/个体户），管理员微信可扫码。
- 小程序 AppID、AppSecret（重置后立即更新后台配置）。
- 微信支付商户号已开通并完成与小程序 AppID 的关联（如需微信支付）。

### 3.2 域名与证书
- 已备案域名（大陆主体）；香港服务器也需按微信要求完成域名备案/资质核验。
- `mksup.top` 已签发 Let's Encrypt 证书，HTTPS 可访问且证书链完整。
- 后台 `mp_request_domain` 填 `https://mksup.top`；`mp_business_domain` 填同一域名（含需要 web-view 的页面域名）。

### 3.3 页面与文案
- 隐私保护指引：收集的信息类型、用途、第三方 SDK（微信支付/客服）逐项填写。
- 用户协议、隐私政策页面可公开访问（HTTPS），链接填入后台。
- 客服能力：站内客服已可用；如用微信客服/企微，填写 `mp_kefu_url`。
- 类目资质：按实际经营类目准备（如虚拟商品/自动发卡需对应类目与资质说明）。

### 3.4 功能与账号
- 准备审核测试账号（账号密码登录可用），并在提审备注写明「审核账号：xxx / 密码：xxx」。
- 确认余额支付流程可走通；微信支付未接入时在提审说明中注明「当前仅余额支付」。
- 关闭与审核无关的营销弹窗、外部跳转。

## 4. 开发者工具与后台白名单怎么配

### 4.1 微信公众平台（小程序后台）
1. **开发管理 → 开发设置 → 服务器域名**
   - request 合法域名：`https://mksup.top`
   - uploadFile / downloadFile 合法域名：按需添加 `https://mksup.top`
   - socket 合法域名：如未使用可留空
2. **开发管理 → 开发设置 → 业务域名**
   - 添加 `mksup.top`，按提示下载校验文件放到 `public/` 根目录（Nginx 需允许访问），校验通过后保存。
3. **开发管理 → 开发设置 → 小程序代码上传**
   - 配置 IP 白名单（如使用 CI 上传）或使用开发者工具手动上传。
4. **功能 → 订阅消息**
   - 选用模板并记录模板 ID，填入后台 `mp_subscribe_templates`。
5. **设置 → 基本设置 → 服务类目 / 隐私与安全**
   - 补齐类目、隐私保护指引；隐私协议链接与后台一致。

### 4.2 微信开发者工具
1. 导入 `miniprogram/` 目录，AppID 使用注入后的真实 AppID（或工具内手动选择）。
2. **详情 → 本地设置**：正式联调时勾选「不校验合法域名…」仅在开发阶段使用；提审前取消勾选，确保域名合法。
3. **详情 → 项目配置**：确认 `project.config.json` 的 `appid`、`compileType=miniprogram`。
4. 上传前执行一次 `node scripts/inject-config.js`，并在「版本管理」中确认 AppID 与域名正确。
5. 体验版二维码先自测：登录、商品、下单、余额支付、订单查询、客服。

### 4.3 服务器 / Nginx
- 80 端口仅用于 ACME 校验与 301 跳转；443 反向代理到应用（容器 `mkshop-nginx` 的 8080）。
- 证书路径建议 `/etc/nginx/ssl/mksup.top/fullchain.pem`、`privkey.pem`；续期后 `nginx -s reload`。
- `public/` 下微信校验文件需可直接访问（不要被 SPA 重写规则拦截）。
- 确认 `https://mksup.top/index.php?s=/mp/config` 返回 `code=0` 且不含 `appsecret` / `apiv3` / `cert_path` 字段。

## 5. 提审与发布顺序（建议）

1. 后台填完小程序配置，开启 `mp_release_enable`，微信登录/支付保持关闭（除非已联调完成）。
2. 执行构建注入 → 开发者工具上传体验版 → 真机自测账号密码登录与余额支付。
3. 提交审核：备注测试账号、说明「微信授权登录/微信支付暂未开启」。
4. 审核通过后发布；后续开启微信能力时，先改后台开关与密钥，再重新发版（客户端按 `/mp/config` 动态展示）。
5. 在 `mp_audit_status` 记录版本号、提交/通过时间与驳回原因，便于追溯。

---

## 6. 安全红线

- 小程序代码、构建产物、日志中不得出现 AppSecret、APIv3 密钥、商户证书私钥。
- `/mp/config` 只返回公开字段；后台配置页仅平台管理员可访问（复用 `sys/config_group_form` 权限点）。
- 微信支付回调必须验签；未开启微信支付时直接拒绝回调。
- 证书私钥文件权限最小化（`600`），目录不通过 Nginx 静态暴露。
