# 处理订单

> 来源：doc.kasushou.com/api/v2api/61

处理订单接口

 
 
 
#### 简要描述：
后台管理员处理平台自营订单接口

#### 请求URL：
`http(s)://平台域名/api/admin/v1/order/dual`

#### 请求方式：
`POST`

#### 请求参数：
