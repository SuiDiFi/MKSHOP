# 订单列表

> 来源：doc.kasushou.com/api/v2api/161

订单列表接口

 
 
 
#### 简要描述：
订单列表查询接口(系统版本1.7.7补丁包新增)

#### 请求URL：
`http(s)://平台域名/api/v1/order/list`

#### 请求方式：
`POST`
