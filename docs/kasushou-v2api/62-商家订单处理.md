# 商家订单处理

> 来源：doc.kasushou.com/api/v2api/137

商家订单处理

 
 
 
#### 简要描述：
供货商处理订单接口

#### 请求URL：
`http(s)://平台域名/api/mer/v1/order/dualOrder`

#### 请求方式：
`POST`
