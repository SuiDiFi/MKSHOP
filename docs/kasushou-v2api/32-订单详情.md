# 订单详情

> 来源：doc.kasushou.com/api/v2api/49

订单详情接口

 
 
 
#### 简要描述：
订单详情查询接口（订单同步建议使用订单异步回调处理）

#### 请求URL：
`http(s)://平台域名/api/v1/order/info`

#### 请求方式：
`POST`

#### 请求参数：
