# 商品变更通知

> 来源：doc.kasushou.com/api/v2api/143

商品变更通知

 
 
 
#### 简要描述：
商品信息变动通知

1.本接口为POST,验证回调sign不参与签名
2.接收到推送后,请返回字符串ok,否则视为不成功,将会按照时间阶梯延迟5|10|15|20|25分钟继续进行通知回调,最多回调5次。

#### 签名算法（php demo）：

```
`/**
 * 验证回调
 * @param $post 请求参数
 * @return bool
 */
public function verify($post)
{
 $sign = $post['sign'] ?? '';
 unset($post['sign']);
 $data = [
 'id' => $post['id'],
 'time' => $post['time'],
 ];
 ksort($data); //排序post参数
 try {
 $newsign = sha1($post['time'] . json_encode($data, 256) . 密钥);//签名
 } catch (\Throwable $e) {

 }
 return !empty($newsign) && $newsign == $sign;
}
`
