# 商品详情

> 来源：doc.kasushou.com/api/v2api/45

商品详情接口

 
 
 
#### 简要描述：
商品详情信息接口

#### 请求URL：
`http(s)://平台域名/api/v1/goods/info`

#### 请求方式：
`POST`

#### 请求参数：

13位时间戳（毫秒） | 
1696644296195 | 
 |

|

string |

是否必填 |

 |
