# 订单撤单回调

> 来源：doc.kasushou.com/api/v2api/162

订单撤单回调

 
 
 
#### 简要描述：
订单撤单异步回调接口

1.验证回调sign不参与签名

#### 签名算法（php demo）：

```
`/**
 * 验证回调
 * @param $post 请求参数
 * @return bool
 */
public function verify($post)
{
 $sign = $post['sign'] ?? '';
 unset($post['sign']);
 ksort($post); //排序post参数
 $newsign = sha1($post['time'] . json_encode($post, 256) . 密钥);//签名
 return $newsign == $sign;
}
`
